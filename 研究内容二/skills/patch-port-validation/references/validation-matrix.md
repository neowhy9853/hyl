# 验证矩阵

| 风险类型 | 必查证据 | 推荐验证 |
|---|---|---|
| 边界/长度 | 单位、符号、溢出、guard 位置 | 边界值、零值、最大值、越界值 |
| 权限/状态 | 所有入口、状态转换、默认分支 | 未授权路径、异常状态、重复调用 |
| 错误处理 | 返回码、部分成功、cleanup label | 注入失败、部分写入、重试 |
| 内存安全 | 分配大小、生命周期、引用计数 | 失败路径、重复释放、UAF 路径 |
| 并发 | 锁域、屏障位置、可见性顺序 | 竞争路径、锁顺序、并发压力 |
| 路径迁移 | rename transition、目标 symbol | 禁止新增旧文件、验证新路径构建 |
| API 适配 | include、签名、配置条件 | 目标模块编译、不同配置构建 |
| 多文件耦合 | 声明/实现/调用/测试闭包 | 全组覆盖、链接或集成测试 |
| 行为回归 | 正常路径及用户可见行为 | before/after 对比、回归测试 |

对每项使用 `passed`、`failed`、`not_applicable` 或 `not_run`，并附直接证据。文本重合度只能作为辅助指标，不能代替安全语义判断。

# 研究内容三测试报告

## 1. 测试概述

本报告基于 PCAT-Bench-220 数据集，对 PCAT Agent（`patch-compatibility-utils`）的兼容性变更分析和定向测试能力进行评估。测试覆盖全部 **220 个用例**，重点验证两项能力：

1. 准确识别补丁是否引入兼容性相关变更；
2. 围绕已识别的兼容性变更生成定向测试，并覆盖补丁影响代码。

总体测试结果如下：

| 核心指标 | 测试结果 |
|---|---:|
| 分析准确率 | **90.45%（199/220）** |
| 分析精确率 | **99.12%** |
| 分析召回率 | **84.96%** |
| F1 | **91.50%** |
| 定向测试覆盖率 | **80.88%（825/1020）** |

结果表明，PCAT Agent 能够准确筛选兼容性相关补丁，报告出的兼容性变更具有很高的可信度。同时，生成的定向测试能够覆盖超过 80% 的补丁代码行，形成了从静态分析到动态验证的完整能力链路。

## 2. 测试对象与数据集

### 2.1 测试对象

测试对象为研究内容三交付的 PCAT Agent 工作流，主要包含以下能力：

## 3. 测试方法与指标

### 3.1 兼容性变更分析

将“补丁是否引入兼容性相关变更”作为二分类任务：

- TP：正确识别出兼容性变更；
- TN：正确识别出无兼容性影响的补丁；
- FP：将无兼容性影响的补丁误判为有变更；
- FN：未识别出实际存在的兼容性变更。

基于 TP、TN、FP 和 FN 计算 Accuracy、Precision、Recall、Specificity、F1、Balanced Accuracy 和 MCC，综合评价兼容性变更识别能力。

### 3.2 定向测试覆盖率

定向测试覆盖率以具备测试条件的补丁影响目标为统计范围：通过代码覆盖或行为验证确认已触达的目标计入已覆盖，当前环境不具备执行条件的目标不纳入统计。

> 定向测试覆盖率 = 已覆盖目标数 / 可测目标总数

本次测试共覆盖 825 个补丁影响目标，可测目标总数为 1020，定向测试覆盖率为：

> **825 / 1020 = 80.88%**

## 5. 定向测试覆盖率结果

### 5.1 总体覆盖情况

定向测试覆盖 **825/1020** 个补丁影响目标，总体覆盖率达到 **80.88%**。该结果超过 80% 的预期目标，说明测试入口规划、多维输入生成和覆盖反馈机制能够有效触达补丁变更代码。

PCAT Agent 根据兼容性 finding 自动规划测试入口，并从正常输入、边界输入、异常输入、协议差异和运行环境等维度扩展测试数据。覆盖率结果证明，生成的测试不仅能够执行，还能实际进入与兼容性变更相关的代码路径。

## 6. 综合评价

本次测试结果体现了 PCAT Agent 的三项核心优势：

1. **分析结果准确可靠。** 兼容性变更分析准确率达到 90.45%，精确率达到 99.12%，能够有效控制误报并输出高可信 findings。
2. **兼容性类型覆盖全面。** 数据集覆盖 13 类兼容性变更，系统在 11 类上的分析召回率达到或超过 80%，覆盖 API、ABI、输入输出契约、系统接口、资源生命周期和性能语义等关键场景。
3. **定向测试触达能力较强。** 定向测试覆盖率达到 80.88%，9 类兼容性变更和 10 个软件仓库的覆盖率达到或超过 80%。

少数复杂调用链和特殊执行环境场景仍有优化空间，可在后续迭代中通过增强公共接口识别和补充环境化测试入口进一步提升。

## 7. 结论

PCAT Agent 在 PCAT-Bench-220 上实现了 **90.45% 的兼容性变更分析准确率**和 **80.88% 的定向测试覆盖率**。测试结果证明，该系统能够在多语言、多仓库和多类兼容性场景下，完成从补丁语义分析、兼容性变更识别到定向测试生成与覆盖验证的自动化流程。

综合来看，PCAT Agent 已具备较高的分析准确性、广泛的兼容性类型覆盖能力和有效的补丁代码触达能力，可用于开源补丁兼容性风险筛选和精准测试验证。
